# 🏠 AirBNB Clone Backend

This is the backend of an AirBNB Clone project built using Node.js, Express, and MongoDB.

---

## 🚀 Features

- User Authentication (Login / Signup)
- Add / Edit / Delete Listings
- REST API
- Database Integration (MongoDB)
- Image Upload (optional)

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB


---

## 📁 Project Structure


├── controllers/
├── models/
├── routes/
├── views/
├── public/
├── app.js


---

## ⚙️ Installation

1. Clone the repository


git clone https://github.com/your-username/AirBNB-Clone-Backend.git


2. Install dependencies


npm install


3. Start the server
npm start

## 🌐 API Endpoints

| Method | Route | Description |
|------|------|-------------|
| GET | /homes | Get all homes |
| POST | /homes | Add new home |
| GET | /homes/:id | Get single home |
| POST | /favourite | Add to favourite |
